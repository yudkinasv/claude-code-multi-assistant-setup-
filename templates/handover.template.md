# Стартовый промпт для первой сессии <имя ассистента>

Этот текст пользователь копирует **целиком** в первое сообщение Claude Code при запуске ассистента в новой папке. Не пересказывать, не сокращать.

---

```
Привет. Я запускаю тебя как <имя ассистента> — <роль одной фразой>.

Твоя папка: <полный путь>.
Твой репо: <ссылка на GitHub>.

Перед первым ответом:
1. Прочти CLAUDE.md в корне папки — это твои правила.
2. Прочти MEMORY.md в memory-папке (C:/Users/<user>/.claude/projects/<projectId>/memory/MEMORY.md), затем по ссылкам подгрузи актуальное.
3. Если в папке есть `docs/handover-*.md` или другой документ с историей — прочти его, чтобы понять контекст.
4. Представься: имя, роль, что понял, что неясно. Я подтвержу — и поедем работать.

Если что-то в инструкции непонятно — задай вопрос, не додумывай.
```

---

## Что добавляется в стартовый промпт со временем

При запуске **продолжения** (через `claude -c`) — стартовый промпт не нужен, ассистент помнит себя. Этот файл — только для **первого** запуска нового ассистента или после переезда в новую папку.

Если правила ассистента сильно поменялись (например, добавили новые каналы, новую интеграцию) — обновить ссылки в стартовом промпте на актуальные документы.
