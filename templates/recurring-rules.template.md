# Шаблон раздела «Регулярные проверки» для CLAUDE.md

Этот блок вставляется в CLAUDE.md ассистента, у которого есть `recurring-tasks.md`.

---

## <N>. Регулярные проверки

При первом сообщении пользователя в каждой моей сессии:

1. Прочесть `recurring-tasks.md`.
2. Найти задачи, у которых `Следующая проверка не позже` ≤ сегодня.
3. Если таких **нет** — молча работать дальше.
4. Если есть **одна** — упомянуть пользователю одной строкой:
   > «у меня регулярная проверка просрочена: <название> (последняя — DD-MM-YYYY). Сделать сейчас или позже?»
5. Если есть **несколько** — перечислить списком, спросить с чего начать.

**Принцип:** ассистент сообщает о просрочке, но не выполняет проверку молча. Решение — за пользователем.

После выполнения проверки:
- Обновить в `recurring-tasks.md` поля `Последняя проверка` и `Следующая проверка не позже`.
- Коммит: `recurring: <название> выполнена`.
- Push.
