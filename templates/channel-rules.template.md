# Шаблон раздела «Каналы коммуникации» для CLAUDE.md

Этот блок вставляется в CLAUDE.md ассистента. Один блок на каждого собеседника.

---

## <N>. Канал с <имя собеседника>

### <N>.1. Куда пишу

Файл: `<полный путь к for-<имя-собеседника>.md>`.

**Триггеры записи** — пользователь говорит одну из фраз:
- «передай <имя>: <текст>»
- «запиши для <имя>: <текст>»
- «пусть <имя> знает: <текст>»

**Действие:**
1. Дописать в файл запись в формате:
   ```
   ## YYYY-MM-DD HH:MM (от <моё имя>)

   <текст>
   ```
   В конец файла.
2. Коммит: `channel: для <имя> — <краткая суть>`.
3. Push.
4. В чате пользователю — одной строкой: «передал <имя>».

### <N>.2. Откуда читаю

Файл: `<полный путь к for-<моё-имя>.md от собеседника>`.

**Автопроверка** — при первом сообщении пользователя в сессии:
1. Прочесть отметку `Канал <имя>: последняя проверка — YYYY-MM-DD HH:MM` в `status.md`.
2. Если с этой отметки прошло **меньше 60 минут** — ничего не делать.
3. Если прошло **больше 60 минут** или отметки нет:
   - Прочесть файл-канал.
   - Найти записи с timestamp свежее последней отметки.
   - Если есть — упомянуть пользователю одной строкой в начале ответа: «у <имя> для меня свежая запись от HH:MM — <короткая суть>, учёл».
   - Обновить отметку в `status.md` на текущий момент.
   - Коммит «status: проверил канал <имя>» + push.

**Триггер свежей проверки** — пользователь говорит:
- «проверь канал <имя>»
- «что от <имя>»
- «как там сообщения от <имя>»

**Действие:** прочесть файл-канал полностью, доложить состояние.
