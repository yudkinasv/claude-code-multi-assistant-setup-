# AGENT-PROMPT — делегировать сборку своему Claude Code

Этот файл — **готовый стартовый промпт**, который ты копируешь в первое сообщение своему Claude Code. Code прочитает методичку и проведёт тебя через сборку оргструктуры в режиме интервью.

---

## Как использовать

1. **Склонируй** этот репо в любую папку на своём компьютере:
   ```bash
   git clone https://github.com/yudkinasv/claude-code-multi-assistant-setup-.git
   cd claude-code-multi-assistant-setup-
   ```

2. **Открой Claude Code** в этой папке (`claude` в терминале).

3. **Скопируй текст промпта ниже** (всё, что в кодовом блоке) — целиком, без правок — и отправь первым сообщением.

4. **Code прочитает методичку и начнёт интервью.** Дальше — отвечай на его вопросы, выполняй то, что он попросит сделать руками (создать репо на GitHub, получить токен), и за 2-4 часа диалога у тебя будет готовая оргструктура.

---

## Что Code сделает сам, а что попросит у тебя

### Code делает сам (~70% работы)

- Создание папок (`mkdir`)
- Локальные git-операции (`init`, `config`, `add`, `commit`, `push`)
- Создание `CLAUDE.md`, инструкций ролей, файлов каналов, `recurring-tasks.md` из шаблонов с подстановкой имён.
- Создание worktree-веток (`git worktree add`).
- Тестирование API через curl после получения токена.
- Парсинг ответов API (через Read + grep, не python3).
- Подготовка фрагментов для `settings.json` Windows Terminal.
- Тестовый прогон каналов и API в конце.

### Ты сам (~30% работы)

- Создать репо на GitHub в браузере (Code не может).
- Включить 2FA, сохранить recovery-коды на бумаге.
- Получить API-токен в личном кабинете внешнего сервиса.
- Вставить фрагмент в `settings.json` Windows Terminal (физически файл доступен Code, но его правка требует подтверждения; проще — ты сам вставляешь подготовленный кусок).
- Открыть новую вкладку через профиль терминала.
- При первом запуске нового ассистента — набрать `claude` (без `-c`), потом сменить профиль на `claude -c` для следующих запусков.
- Кликать «всегда разрешать» при первом срабатывании каждой команды Bash в allow-list.
