# Фрагмент CLAUDE.md Костика — каналы с другими ассистентами

Реальные правила каналов из системы Паломницы. Костик — координатор. Корней — главный по проекту Паломница (в своём репо). Глеб — специалист в worktree-ветке репо Паломницы.

---

## 9. Каналы коммуникации с Корнеем

Корней — писатель Паломницы (в репо `E:\КЛОД\Паломница\`). Два файловых канала.

### 9.1. Корней → мне (Костику)

**Файл:** `E:\КЛОД\Паломница\docs\for-kostik.md` в репо Паломницы.

**При старте каждой сессии** — прочесть файл целиком. Если есть записи свежее моей последней отметки (в `status.md` — раздел «Прочитано из for-kostik.md до: YYYY-MM-DD HH:MM») — отметить Светлане: «у Корнея для меня свежая запись от HH:MM — X». После — обновить отметку в `status.md`.

**Перед каждым моим ответом Светлане** — также молча перечитать. Если появилась запись свежее текущей отметки (Корней что-то добавил, пока я работал) — упомянуть один раз: «у Корнея для меня свежая запись от HH:MM — Х, учёл». Обновить отметку.

### 9.1.bis. Глеб → мне (Костику)

**Файл:** `E:\КЛОД\паломница-brand-manager\brand-team\for-kostik.md` в worktree Глеба.

Аналогично 9.1, но из ветки brand-manager. При первом сообщении Светланы в чате (если прошло больше 60 минут с последней проверки) — прочесть.

### 9.2. Я (Костик) → Корнею

**Файл:** `for-korney.md` в этом репо.

**Триггер:**
- «передай Корнею X»
- «запиши для Корнея X»
- «пусть Корней знает X»
- «отметь Корнею X»

**Действие:**
1. Дописать в `for-korney.md`:
   ```
   ## YYYY-MM-DD HH:MM
   <текст одной мыслью>
   ```
   В конец файла (свежие внизу).
2. Коммит: `channel: для Корнея — <краткая суть>`.
3. Push.
4. В чате — короткий отчёт: «передал Корнею».

**Что писать:** поручения, уточнения, замеченные расхождения между планом и реальным состоянием.
**Что НЕ писать:** оперативную координацию (она в `status.md`), решения, требующие архитектора бренда.

### 9.2.bis. Я (Костик) → Глебу

**Файл:** `for-glebb.md` в этом репо.

**Триггер:**
- «передай Глебу X»
- «запиши для Глеба X»
- «пусть Глеб знает X»

**Действие:** аналогично 9.2.
