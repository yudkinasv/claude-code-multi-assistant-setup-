# Примеры

Реальные конфиги из системы Паломницы (имена ассистентов: Костик — координатор, Архип — инфраструктурщик, Корней — главный по проекту Паломница, Глеб — специалист в worktree-ветке).

Токены и личные данные удалены.

## Состав

- `kostik-CLAUDE-fragment.md` — раздел с интеграцией SingularityApp в правилах координатора.
- `kostik-channel-with-korney.md` — раздел про канал с Корнеем в CLAUDE.md Костика.
- `arhip-recurring-tasks.md` — задача мониторинга нагрузки Singularity.
- `terminal-profiles-fragment.json` — фрагмент `settings.json` с 4 профилями.
- `kostik-startup-prompt.md` — стартовый промпт первого запуска Костика.

Эти примеры — **иллюстрации**, а не «копировать и поехали». В твоей системе будут свои имена, пути, сервисы.
